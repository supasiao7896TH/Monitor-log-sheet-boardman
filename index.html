คู่มือการใช้งานระบบ (Comprehensive Manual)

เรียนรู้วิธีการใช้งาน Plant Log Analyzer ขั้นสุดยอด ตั้งแต่การนำเข้าข้อมูลไปจนถึงการแชร์รายงาน Infographic

1 การนำเข้าข้อมูลอย่างเข้มงวด (Strict Import)

  • ไปที่เมนู "นำเข้าข้อมูล" ด้านซ้ายมือ ลากไฟล์ Log sheet (รองรับ .xls, .xlsx, .csv) ลงในกล่อง
  • ระบบ Strict Numeric Engine: ระบบจะคัดกรองเฉพาะตัวเลขทางคณิตศาสตร์เท่านั้น ขยะข้อความอย่าง N/A, OFF, SEU หรือหัวตารางที่หลุดมาอย่าง Inlet จะถูกเตะทิ้งทั้งหมด
  • ระบบ Deep Date Radar: สแกนหาวันที่จากชื่อไฟล์ หรือคำว่า "DATE" ในเอกสาร และนำไปเชื่อมโยงข้อมูลในทุกๆ Sheet ให้เป็นวันเดียวกันโดยอัตโนมัติ

2 การตั้งค่าเกณฑ์ควบคุม & จัดการ Standby

  • เมนู Tag Master: หากไฟล์ Excel ระบุค่า Min/Max ผิด สามารถกดปุ่ม "Edit Overrides" เพื่อบังคับใช้ค่าควบคุมใหม่ได้ — ค่าที่ตั้งไว้จะอยู่ถาวร ไม่ถูกลบเมื่อ import ไฟล์ใหม่ หรือกดปุ่ม "ล้างฐานข้อมูล" (ปุ่มนั้นล้างเฉพาะ Records เท่านั้น)
  • ระบบ Absolute Zero Shield: บอกลาปัญหา 0.00 กวนใจ! ไม่ว่าลิมิตของเครื่องจักรจะเป็นอย่างไร หากอ่านค่าได้ `0` หรือใกล้เคียงศูนย์ ระบบจะเพิกถอนสถานะสีแดง และเปลี่ยนเป็น STANDBY (เครื่องปิด/การ์ดสีเทา) อัตโนมัติ — ปิดการทำงานนี้เฉพาะ Tag ได้ด้วยติ๊ก "ปิดการตรวจจับ Standby อัตโนมัติ" ในหน้า Edit Overrides
  • Force Standby: สำหรับเครื่องที่ค่าปกติตอนหยุดทำงานไม่ใกล้ศูนย์ (เช่น sensor สั่นสะเทือนที่อ่านค่า ~13 ตอนเครื่องจอด) ให้ติ๊ก "เครื่องอยู่ในสถานะ Standby ตอนนี้" เพื่อบังคับให้ Tag นั้นเป็น Standby เสมอโดยไม่สนค่าที่อ่านได้

3 วิเคราะห์และบันทึกปัญหา (Dashboard)

  • แถบ Time Breakdown: ด้านบนของ Dashboard ใช้สำหรับกรองเวลาของแต่ละกะ
  • การ์ดสีแดง (Abnormal): คือพารามิเตอร์ที่หลุดเกณฑ์ คลิกที่การ์ด เพื่อดูกราฟแนวโน้มสถิติ (UCL/LCL)
  • Action Remark: พิมพ์บันทึกการแก้ไขปัญหา การ์ดจะเปลี่ยนเป็น "สีส้ม (Acknowledged)" เพื่อบ่งบอกว่ารับทราบปัญหาแล้ว

4 ระบบคัดกรองวิกฤตอัตโนมัติ (Auto-Select)

  • ใช้ "เมนูคัดเลือกอัตโนมัติ ⚡" เพื่อเลือกจำนวนพารามิเตอร์เข้าสู่รายงาน (Top 3, Top 5, Top 10)
  • ระบบจะคำนวณเปอร์เซ็นต์ความหลุดขอบ และคัด พารามิเตอร์ที่ไม่ซ้ำกัน ที่อาการหนักที่สุดให้แบบอัตโนมัติ (ข้ามค่า Standby เด็ดขาด)
  • หากต้องการเริ่มเลือกใหม่ สามารถกดปุ่ม "✕ ล้างการเลือก" เพื่อเคลียร์เครื่องหมายถูกออกทั้งหมด
  • ต้องการรวมทุกพารามิเตอร์ที่มองเห็นในตารางตอนนี้เข้ารายงาน ไม่ว่าจะปกติหรือผิดปกติ ให้กดปุ่ม "เลือกทั้งหมด" แทนการเลือกทีละแถว

5 สร้าง Infographic Report ส่งกะ

  • เมื่อเลือกพารามิเตอร์แล้ว กดปุ่ม "สรุปเป็นรูปภาพ (Smart)" ที่แถบด้านล่าง
  • กรอกข้อมูลกะการทำงาน ข้อมูลบนภาพ Live Preview จะอัปเดตตามทันที
  • Offline Smart Agent: ระบบจะเขียน "สรุปภาพรวมกะ (Executive Summary)" ไว้ด้านล่างสุดของรูปภาพให้แบบอัตโนมัติ
  • สลับรูปแบบรายงาน Card ⇄ Table: ที่มุมขวาบนของ Live Preview เลือกได้ว่าจะให้รูปที่ export ออกมาแสดงเป็นการ์ดแยกรายตัว หรือเป็นตารางรวมทุกพารามิเตอร์ในหน้าเดียว
  • กด "Save as Image (JPG)" เพื่อบันทึกรูปและแชร์เข้า LINE กลุ่มผู้บริหารได้เลย! ระบบจะคัดลอกรูปเข้า Clipboard ให้อัตโนมัติด้วย — ไปวาง (Ctrl+V) ที่ Excel ได้ทันทีโดยไม่ต้องเปิดไฟล์ก่อน

6 ระบบแนะนำการแก้ไข (Countermeasure)

  • ในหน้าต่างบันทึกปัญหา กดปุ่ม "Auto-Draft" เพื่อให้ระบบดึงคำแนะนำที่ผูกกับ Tag No และทิศทาง (สูง/ต่ำ) มาเติมในช่อง Resolution Remark ให้อัตโนมัติ
  • หากคำแนะนำมาจากฐานข้อมูลที่ทีมวิศวกรรมคิวเรทไว้ล่วงหน้า จะมี Badge "จากคู่มือ" กำกับไว้ — คำแนะนำกลุ่มนี้มีความสำคัญเหนือกว่าเสมอ
  • เมนู "Countermeasure" ที่แถบซ้าย เป็นตารางให้เพิ่ม/แก้ไข/ลบคำแนะนำของตัวเองสำหรับ Tag ที่ยังไม่มีในคู่มือ — ข้อควรระวัง: ถ้า Tag+ทิศทางนั้นมีคำแนะนำจากคู่มืออยู่แล้ว ข้อมูลที่เพิ่มเองจะยังไม่ถูกใช้งาน จนกว่าคำแนะนำจากคู่มือจะถูกลบออกก่อน

7 ซิงก์ข้อมูลกลับ Excel อัตโนมัติ (Excel Bridge)

  • เมื่อกด "Save Remark" ระบบจะพยายามเขียน Resolution Remark กลับไปเป็น Comment บน cell ต้นฉบับใน Excel ให้อัตโนมัติ (ไม่ต้องพิมพ์ซ้ำในไฟล์ Excel เอง)
  • ข้อกำหนดก่อนใช้งาน: ต้องรันโปรแกรม Local Bridge (bridge/excel-bridge.ps1) ค้างไว้บนเครื่อง และต้องเปิดไฟล์ Excel ต้นฉบับค้างไว้ระหว่างซิงก์ (ดูวิธีติดตั้ง/ตั้ง autostart ใน bridge/README.md)
  • ข้อความสถานะที่ขึ้นใต้ช่อง Resolution Remark บอกผลลัพธ์ 6 แบบ: บันทึกสำเร็จ / ไฟล์เก่าที่ import มาก่อนฟีเจอร์นี้ (ต้อง import ใหม่) / ไม่พบ Local Bridge เปิดอยู่ / ไม่พบไฟล์นี้เปิดอยู่ใน Excel / มีคนพิมพ์คอมเมนต์ไว้ในเซลล์แล้ว (ระบบจะไม่เขียนทับให้) / และ error ทั่วไป
  • สำหรับเครื่องที่ใช้ร่วมกันหลายคน (Shared PC) มีไฟล์ launcher ผ่าน Excel Hyperlink ให้เปิด Bridge ได้ง่ายโดยไม่ต้องเข้า PowerShell เอง
  • เปิด Bridge จากหน้า Web App ได้เลย (V29.103): ปุ่ม "เปิด Excel Bridge" ข้าง sync indicator มุมล่างซ้าย (โผล่เฉพาะตอนสถานะเป็น "LOCAL MODE") — ต้อง import bridge/register-protocol.reg ในเครื่องก่อนใช้งานครั้งแรก (ไม่ต้องใช้สิทธิ์ Admin) ดูวิธีตั้งค่าใน bridge/README.md

8 นำเข้าข้อมูลอัตโนมัติจาก Excel (Auto-Import)

  • เมื่อรัน Local Bridge ค้างไว้ (ดูข้อกำหนดใน Step 7) และเปิดไฟล์ log sheet ต้นฉบับค้างไว้ใน Excel ตามปกติ ระบบจะ ดึงข้อมูลจากไฟล์เข้า Web App ให้เองอัตโนมัติทุก ~5 นาที ไม่ต้องลากไฟล์เข้าหน้า "นำเข้าข้อมูล" ซ้ำเองอีก
  • สั่ง Save ให้เองก่อนดึงข้อมูลทุกรอบ (V29.107): สูตร PI Datalink ในไฟล์คำนวณค่าล่าสุดแสดงบนจอ Excel แบบสดได้เอง แต่ค่านั้นจะยังไม่ถูกเขียนลงไฟล์จริงจนกว่าจะมีการ Save — Bridge จะสั่ง Excel บันทึกไฟล์ให้เองแบบไม่มีเงื่อนไขทุกรอบที่เช็คข้อมูลใหม่ (ทุก ~5 นาที) ไม่ต้องกด Ctrl+S เองอีกต่อไป ค่าตามเวลาที่ควรมี (เช่น 03:00/09:00/15:00/21:00) จะขึ้นในแดชบอร์ดให้เองภายในไม่กี่นาที
  • เปลี่ยนไฟล์วันใหม่ให้เองทุกเที่ยงคืน: ไม่ต้องเปลี่ยนชื่อไฟล์หรือแก้วันที่ในชีตเองทุกเช้า ระบบจัดการให้อัตโนมัติ (รวมถึงเปิดไฟล์ให้เองถ้ายังไม่มีใครเปิดไว้ตอนเปลี่ยนกะ)
  • ถ้ามีปัญหา (เช่น เจอไฟล์มากกว่า 1 ไฟล์ในโฟลเดอร์ที่ Bridge เฝ้าดูอยู่ หรือไฟล์ที่เปิดยังเป็นไฟล์ template เปล่า) จะมีแบนเนอร์แจ้งเตือนสีเหลือง/แดงขึ้นด้านบนของ Dashboard บอกสาเหตุให้ตรวจสอบ

9 สำรอง/กู้คืนข้อมูล & ประวัติการนำเข้า

  • แถบซ้ายล่างมีปุ่ม "สำรองข้อมูล" (ดาวน์โหลดไฟล์สำรอง) และ "กู้คืนข้อมูล" (นำไฟล์สำรองกลับเข้าระบบ) — แนะนำให้สำรองก่อนเปลี่ยนเครื่องหรือล้าง browser data
  • ปุ่ม "ล้างฐานข้อมูล" ลบเฉพาะ Records (ข้อมูล reading ที่ import มา) เท่านั้น — Tag Database และ Master Tag overrides จะไม่ถูกลบ ไม่ต้องตั้งค่าลิมิตใหม่ทุกกะ
  • หากไม่ได้สำรองข้อมูลมานาน จะมีแบนเนอร์แจ้งเตือนสีเหลืองขึ้นที่ด้านบนของ Dashboard ให้กดสำรองได้ทันที
  • หน้า "นำเข้าข้อมูล" มีพาแนล "ประวัติการนำเข้าไฟล์ (Import History)" ไว้ตรวจสอบย้อนหลังว่าเคย import ไฟล์ไหนไปแล้วบ้าง
